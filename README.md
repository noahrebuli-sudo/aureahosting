# aureahosting

## Purpose

This territory holds development work for AUREA, a short-stay property management service. It contains the static website, supporting scripts, content data, and internal audit and brand documents for the AUREA hosting operation.

## Repository structure

- `areas/` - Per-suburb landing pages (Brighton, CBD, Glenelg, Norwood, Prospect, Stirling)
- `assets/` - Email signature images and web font files
- `guides/` - HTML page templates
- `images/` - Photography, logos, and other image assets
- `reports/` - Owner-facing yield report PDFs
- `index.html` - Homepage
- `about.html` - About page
- `areas.html` - Areas overview page
- `contact.html` - Contact page
- `fees.html` - Fees page
- `faq.html` - Frequently asked questions page
- `privacy.html` - Privacy policy page
- `report.html` - Yield report page
- `card.html` - Digital business card page
- `404.html` - Custom 404 error page
- `app.js` - Shared front-end JavaScript
- `data.js` - Site content data
- `ed-home.js` - Additional front-end script
- `lucide.js` - Bundled Lucide icon library
- `AUDIT.md` - Ongoing audit log
- `AUDIT-2026-04-22.md` - Point-in-time audit snapshot
- `BRAND.md` - Brand guidelines
- `CMS-AUDIT.md` - CMS audit notes
- `SECURITY-AUDIT.md` - Security audit notes
- `_redirects` - Netlify redirect rules
- `_headers` - Netlify response header rules
- `robots.txt` - Search engine crawler rules
- `llms.txt` - LLM access policy
- `.gitignore` - Git ignore rules
- `aurea-noah.vcf` - Founder contact card
- `Aurea-Owner-Agreement.html` - Owner agreement document
- `Aurea-Owner-Appointment-Form.html` - Owner appointment form
