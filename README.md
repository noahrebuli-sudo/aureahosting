# aureahosting

## Purpose

This territory holds the development work for AUREA hosting, a short-term rental management service operating across metropolitan Adelaide. The repository contains the public-facing website, owner-facing document templates, site configuration, internal audit records, and supporting static assets.

## Structure

- `areas/` - HTML pages for individual service areas (Brighton, Glenelg, CBD, Stirling, Norwood, Prospect)
- `assets/` - Web fonts and email signature image assets
- `guides/` - Guide page templates for owners or guests
- `images/` - Site imagery including editorial photography and brand graphics
- `tools/` - Utility HTML pages (e.g. property inspection form)
- `index.html` - Site homepage
- `about.html`, `contact.html`, `faq.html`, `fees.html`, `areas.html`, `report.html`, `privacy.html`, `card.html`, `404.html` - Site pages
- `Aurea-Owner-Agreement.html`, `Aurea-Owner-Appointment-Form.html` - Owner document templates
- `app.js`, `data.js`, `ed-home.js`, `lucide.js` - Site JavaScript files
- `AUDIT.md`, `AUDIT-2026-04-22.md`, `CMS-AUDIT.md`, `SECURITY-AUDIT.md`, `BRAND.md` - Internal audit and brand documentation
- `_headers`, `_redirects` - Hosting platform configuration files
- `robots.txt`, `llms.txt` - Crawler and AI-agent policy files
- `aurea-noah.vcf` - Contact card file
- `f961de789f114dc2b5023ab71e09cc0d.txt` - Domain verification file
