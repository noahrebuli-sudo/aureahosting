# aureahosting

## Overview

This is the hosting and development repository for AUREA. It contains the static site files, assets, and internal documents that make up the project.

## Repository Structure

- `areas/` - HTML pages for individual service area locations
- `assets/` - Fonts and email asset files
- `guides/` - Guide page templates
- `images/` - Image assets used across the site
- `index.html` - Site home page
- `about.html` - About page
- `areas.html` - Areas overview page
- `contact.html` - Contact page
- `faq.html` - Frequently asked questions page
- `fees.html` - Fees page
- `services.html` - Services page
- `privacy.html` - Privacy policy page
- `report.html` - Report page
- `card.html` - Card page
- `404.html` - Custom error page
- `app.js` - Main site JavaScript
- `data.js` - Site data
- `lucide.js` - Icon library
- `ed-home.js` - Contents under review
- `_redirects` - Hosting redirect rules
- `_headers` - Hosting header rules
- `robots.txt` - Search engine directives
- `llms.txt` - Contents under review
- `BRAND.md` - Brand documentation
- `AUDIT.md` - Internal audit record
- `AUDIT-2026-04-22.md` - Internal audit record dated 2026-04-22
- `SECURITY-AUDIT.md` - Security audit record
- `CMS-AUDIT.md` - CMS audit record
- `Aurea-Owner-Agreement.html` - Owner agreement document
- `Aurea-Owner-Appointment-Form.html` - Owner appointment form
- `aurea-noah.vcf` - Contact card file
- `.gitignore` - Git ignore rules
