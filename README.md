# aureahosting

## Overview

This repository contains the source files for the Aurea Hosting website - a static, vanilla HTML/CSS/JavaScript site for a short-term rental management service based in Adelaide, South Australia. The site markets property management services to Adelaide property owners and covers pages for services, areas, FAQ, a revenue calculator, and an application form.

## Repository Structure

Top-level files and directories present in the repository:

- `index.html` - Homepage with hero section and revenue calculator
- `services.html` - Services overview page
- `areas.html` - Coverage areas page with map
- `contact.html` - Owner application form
- `faq.html` - Frequently asked questions
- `fees.html` - Fees information page
- `about.html` - About page
- `report.html` - Report page
- `card.html` - Digital business card page
- `privacy.html` - Privacy policy
- `why-us.html` - Competitor comparison page
- `404.html` - Custom 404 error page
- `Aurea-Owner-Agreement.html` - Legal owner agreement document
- `Aurea-Owner-Appointment-Form.html` - Printable owner appointment form
- `app.js` - Main site interactions, calculator logic, and animations
- `data.js` - Site data
- `ed-home.js` - Additional JavaScript
- `lucide.js` - Local copy of the Lucide icon library
- `styles.css` - Full design system and all page styles (~5000 lines)
- `robots.txt` - Crawler rules
- `_redirects` - Redirect rules for the hosting platform
- `_headers` - HTTP header rules for the hosting platform
- `llms.txt` - LLM access policy file
- `aurea-noah.vcf` - Founder contact card
- `areas/` - Individual suburb landing pages (CBD, Glenelg, Brighton, Norwood, Prospect, Stirling)
- `guides/` - Guide page template
- `tools/` - Internal tooling pages
- `images/` - Site photography, logos, favicons, and editorial images
- `assets/` - Fonts (Switzer, Satoshi in WOFF2 and OTF formats) and email signature assets
- `AUDIT.md` - Full site audit document
- `AUDIT-2026-04-22.md` - Dated audit snapshot
- `BRAND.md` - Brand system reference (colours, typography, spacing, tone of voice)
- `CMS-AUDIT.md` - CMS audit document
- `SECURITY-AUDIT.md` - Security audit document

## Status

This repository is in active development. The site is not yet considered production-ready; multiple audit documents note open items across SEO, accessibility, conversion, and code quality. No build pipeline or CI/CD configuration is present - deployment is manual.
