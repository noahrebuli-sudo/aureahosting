# aureahosting

## Purpose

This repository is the static site for AUREA, a short-term property management service based in Adelaide, South Australia. It contains all pages, assets, and scripts that make up the public-facing website for AUREA Hosting. The site presents information about services, area coverage, fees, and owner resources.

## Structure

Top-level HTML pages:

- `index.html` - home page
- `about.html` - about page
- `areas.html` - areas overview
- `contact.html` - contact page
- `card.html` - business card page
- `faq.html` - frequently asked questions
- `fees.html` - fee information
- `services.html` - services page
- `report.html` - report page
- `privacy.html` - privacy policy
- `404.html` - error page
- `Aurea-Owner-Agreement.html` - owner agreement document
- `Aurea-Owner-Appointment-Form.html` - owner appointment form

Top-level directories:

- `areas/` - individual area pages (brighton, cbd, glenelg, norwood, prospect, stirling)
- `assets/` - fonts and email assets
- `guides/` - guide page templates
- `images/` - site imagery including editorial and UI images

Key scripts and data:

- `app.js` - main site script
- `data.js` - site data
- `ed-home.js` - editor home script
- `lucide.js` - icon library

Other files:

- `robots.txt` - crawler directives
- `_headers` - HTTP header rules
- `_redirects` - redirect rules
- `llms.txt` - LLM information file
- `BRAND.md` - brand guidelines
- `aurea-noah.vcf` - contact card

## Status

This repository is actively maintained as a static site. No features or behaviours are generated at build time - all pages are plain HTML files served directly.
