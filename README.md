# aureahosting
dev for AUREA

## Repository structure

- `/` - Root-level implementation: HTML pages (`index.html`, `about.html`, `fees.html`, `faq.html`, etc.), JavaScript files (`app.js`, `data.js`, `ed-home.js`, `lucide.js`), Netlify config (`_headers`, `_redirects`), and supporting directories (`assets/`, `images/`, `areas/`, `guides/`).
- `next/` - Parallel set of HTML pages (`index.html`, `about.html`, `fees.html`, `faq.html`, etc.) with its own `_headers` and `_redirects` config; no JavaScript files at the top level of this subdirectory.

## Status

This repository contains two parallel implementations: the root-level files and the `next/` subdirectory. Their relationship and active status are not yet documented.
