# aureahosting

Development repository for the AUREA hosting site and content.

## Repository layout

Top-level contents include HTML pages, assets, and configuration files for the AUREA hosting site. A `next/` directory also exists and contains redesigned versions of most pages. The relationship between `next/` and the main content, and its deployment status, are not yet documented.

## Status

This territory is under `draft_only` hygiene-level maintenance. Only fixes to docs, tests, dead code, and error handling are in scope - no new features.
