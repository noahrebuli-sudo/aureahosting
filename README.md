# aureahosting

## Overview

This repository contains the static website for Aurea Hosting, a short-term property management service operating in the Adelaide region. The site is built with plain HTML, CSS, and JavaScript - no framework or build step is required. Pages cover public-facing content including property area guides, fees, owner agreements, and contact information. Brand and audit reference documents are also tracked here for contributor reference.
