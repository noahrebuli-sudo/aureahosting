# aureahosting

## Purpose

This repository contains the production website and operational documentation for AUREA hosting. It holds the public-facing HTML pages, supporting scripts, media assets, and in-repo documents covering audits and legal agreements.

## Repository contents

- `index.html` - main homepage
- `about.html` - about page
- `areas.html` - service areas overview page
- `areas/` - individual area pages (cbd, norwood, brighton, glenelg, stirling, prospect)
- `contact.html` - contact page
- `fees.html` - fees page
- `faq.html` - FAQ page
- `card.html` - card page
- `404.html` - custom 404 error page
- `app.js` - main site JavaScript
- `data.js` - site data module
- `ed-home.js` - supplementary JavaScript module
- `lucide.js` - icon library
- `assets/` - fonts and other static assets
- `images/` - site images and editorial photography
- `guides/` - guide page templates
- `next/` - in-progress page variants
- `BRAND.md` - brand reference document
- `AUDIT.md` - general audit document
- `AUDIT-2026-04-22.md` - audit document dated 2026-04-22
- `CMS-AUDIT.md` - CMS audit document
- `SECURITY-AUDIT.md` - security audit document
- `Aurea-Owner-Agreement.html` - owner legal agreement document
- `Aurea-Owner-Appointment-Form.html` - owner appointment form document
- `_redirects` - redirect rules for the hosting platform
- `_headers` - HTTP header rules for the hosting platform
- `llms.txt` - guidance file for language model crawlers
- `aurea-noah.vcf` - contact vCard

## Status

This repository is in production and operational use. Audit documents and legal agreements are maintained in-repo alongside the production website files.
