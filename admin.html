Export & Deploy
Save changes in-session, download a permanent cms.js, or export/import a JSON snapshot.
How content updates work:
Changes saved here are in-memory only — they apply to this browser session but reset on page refresh. To make changes permanent, click Download cms.js and replace the existing cms.js file on your server. Use JSON export/import to transfer settings between sessions or environments.

Save (this session)

Collects all field values, saves them to the in-memory store, and calls applyAureaSettings() so changes are immediately reflected on open site pages.

Download cms.js

Generates a new cms.js file with your current settings baked into AUREA_DEFAULTS. Replace the file on your server to make changes permanent across all visitors.

Export JSON Snapshot

Downloads a aurea-settings.json file with all current settings. Useful for backups or transferring settings between environments.

Import JSON Snapshot

Paste a previously exported JSON snapshot below and click Import to restore those settings into the current session.

Reset to Defaults

Clears all in-session overrides and reloads form fields with the original defaults from AUREA_DEFAULTS. This does not affect any saved server files.
